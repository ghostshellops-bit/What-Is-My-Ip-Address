# 🔍 What Is My IP – Cybersecurity Intelligence Platform

**What Is My IP** is a premium cybersecurity, networking, and internet intelligence platform. It allows users to discover, analyze, and understand their internet connection, IP address, network identity, privacy risks, and online security status.

🔗 **Live Demo:** [whatismyip.com](https://whatismyip.com) *(replace with your domain)*

---

## ✨ Features

### 🛡️ IP Tools
- **What Is My IP** – Auto-detect your public IPv4 and IPv6 address
- **IP Lookup** – Get detailed information about any IP address
- **Bulk IP Lookup** – Check up to 10 IPs at once
- **IP Location** – Geolocation with interactive map
- **IP History** – Track your past IP addresses

### 🔐 Security Tools
- **VPN Checker** – Detect if you're using a VPN
- **Proxy Checker** – Detect proxy connections
- **Tor Checker** – Detect Tor network usage
- **DNS Leak Test** – Check for DNS leaks
- **WebRTC Leak Test** – Check for WebRTC leaks
- **IP Reputation** – Analyze IP reputation
- **IP Abuse Check** – Check abuse reports
- **Blacklist Checker** – Check blacklist status

### 🌐 Network Tools
- **ASN Lookup** – Find Autonomous System Numbers
- **WHOIS Lookup** – Get domain ownership information
- **Reverse DNS** – Find hostnames from IPs
- **Hostname Checker** – Lookup hostname information
- **ISP Lookup** – Find Internet Service Providers
- **CIDR Calculator** – Calculate CIDR ranges
- **BGP Information** – Border Gateway Protocol intelligence

### ⚡ Performance Tools
- **Internet Speed Test** – Test download, upload, and ping

### 📚 Learning Center
- IPv4 & IPv6 Explained
- VPN & Proxy Guides
- DNS & ASN Fundamentals
- CCNA Networking Guide
- Ethical Hacking Basics

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ghostshellops-bit/What-Is-My-Ip-Address.git

# Navigate to project directory
cd What-Is-My-Ip-Address

# Install dependencies
npm install

# Run development server
npm run dev
